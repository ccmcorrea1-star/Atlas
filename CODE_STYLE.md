# Code Style

Este documento define como o código do Atlas deve ser escrito.

## Código

O código deve ser escrito em inglês.

Prefira código pequeno, simples, organizado e legível.

Funções e arquivos devem ter uma responsabilidade clara.

Evite indentação profunda, duplicação e abstrações desnecessárias.

Siga as convenções, formatters e linters da linguagem utilizada.

## Comentários

Comentários devem ser curtos, diretos e escritos em português do Brasil.

```ts
// Carrega a configuração do agente.
const config = loadConfig();
```

Não comente o que já estiver óbvio no código.

## Documentação

A documentação deve ser escrita em português do Brasil, de forma curta e direta.

Ao mencionar arquivos, módulos ou referências, use links sempre que possível.
